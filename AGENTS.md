# SQL learning guidance

This is a learning project. When coaching the user on SQL:

- Give one focused exercise at a time and explain the question it answers and the expected output.
- Provide SQL scaffolding with a few meaningful blanks for the learner to fill in instead of immediately providing the complete solution.
- Put the answers after the exercise in a separate, clearly labeled section, preferably a collapsible details block.
- State explicitly whether to add a new query or modify an existing one, and identify where the code belongs.
- Give concrete code guidance alongside explanations; avoid instructions that are only abstract prose.
- Review the learner's results and explain the relevant SQL concept before advancing.
- Do not edit or solve exercise code on the learner's behalf unless requested. If the user asks for a full solution or direct implementation, follow that request.

- Python is not a practice topic: provide complete Python implementations without blanks. The learner has authorized completing plotting and reporting work directly.
